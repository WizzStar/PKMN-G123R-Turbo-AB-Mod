# G123R Turbo_AB Mod

**v3.0.1** · by **WizzStar**

> Hold **A** or **B** on dialogue and battle text to keep advancing after a short delay — no more mashing. Fully compatible with **Gen1Recomp** (Red/Blue/Yellow), **Gen2Recomp** (Gold/Silver/Crystal), and **Gen 3** (FireRed/LeafGreen/Ruby/Sapphire/Emerald).

## ✨ Features
- **Hold A / B to Advance** — Hold A or B on field dialogue, signs, items, or battle text to automatically advance page after page.
- **Full Gen 1, Gen 2 & Gen 3 Support** — Native compatibility across Red, Blue, Yellow, Gold, Silver, Crystal, FireRed, LeafGreen, Ruby, Sapphire, and Emerald.
- **Smart Choice Suppression** — Automatically pauses whenever a YES/NO prompt, choice menu, or battle command box pops up so you never make accidental selections.
- **Overworld Safety** — Pauses on the overworld map so holding A never re-talks to NPCs in an infinite loop.
- **Soft-Reset Protection** — Turbo automatically pauses while START or SELECT is held to preserve standard soft-resetting (A+B+SELECT+START).
- **Zero-Lag Performance** — Optimized caching and idle state checks for zero CPU overhead.
- **Works with Other Mods** — Modular design and screen opt-outs (`noTurboAB = true` or `denyScreen`) allow seamless integration with custom UI mods.
- **Speed Ladder** — REPEAT SPEED **1–5** (default **3** = tuned feel).
- **Hold Delay** — Tweak initial frame delay before auto-advance kicks in.

## ⚙️ Defaults

| Option | Default | Description |
|---|---|---|
| **TURBO A/B** | ON | Master enable toggle |
| **TURBO A** | ON | Holding A auto-advances text |
| **TURBO B** | ON | Holding B auto-advances text |
| **HOLD DELAY** | 16 | Frames before repeat starts (~267 ms) |
| **REPEAT SPEED** | **3** | Middle of 1–5 speed ladder (10-frame rate) |

### ⚡ Speed Ladder

| Level | Feel | Frames Between Repeats |
|---|---|---|
| 1 | Slower | 14 frames |
| 2 | Slightly Slower | 12 frames |
| **3** | **Default** | **10 frames** |
| 4 | Slightly Faster | 8 frames |
| 5 | Fastest | 6 frames |

## 📦 Installation
1. Download `wizzstar_turbo_ab_v3_0_1.zip`
2. Open the launcher → **MODS** → Enable mod (one install covers Gen 1, Gen 2, and Gen 3)
3. Enjoy rapid text advancing across all Gen 1, Gen 2 & Gen 3 games!
